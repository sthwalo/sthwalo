# Tech Stack

| Layer           | Technology                                   |
|:----------------|:---------------------------------------------|
| Framework       | React 18                                     |
| Language        | TypeScript 5                                 |
| Build tool      | Vite 7 (+ build-time prerendering)           |
| Styling         | Tailwind CSS 3                               |
| Routing         | React Router 7                               |
| Icons           | Lucide React                                 |
| SEO             | Per-page meta tags, Open Graph, sitemap, RSS |
| API             | Node.js + Express 4 (cPanel Node app)        |
| Database        | MySQL (contact form, blog, admin)            |
| Email           | Nodemailer (sendmail transport)              |
| Analytics       | Google Analytics 4 — off unless `VITE_GA_MEASUREMENT_ID` is set, which needs a consent banner first |
| Hosting         | cPanel shared hosting                        |

FIN is a separate product with its own stack and repository; this site only links to
[aosfin.com](https://aosfin.com).
